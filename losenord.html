🔑 Byt redigeringslösenord

Lösenordet lagras som SHA-256-hash – det syns aldrig i klartext på GitHub. Allt sker i din webbläsare, inget skickas någonstans.

1️⃣ Skriv ditt nya lösenord

💡 Filen är publikt läsbar men hashen går inte att "läsa baklänges". Välj ändå ett lösenord du inte använder någon annanstans.

2️⃣ Färdig las.json

✏️ Öppna las.json på GitHub

3️⃣ Så byter du (30 sekunder)

  1. Skriv nytt lösenord ovan → klicka 📋 Kopiera
  2. Klicka ✏️ Öppna las.json på GitHub → markera allt i filen → klistra in
  3. Commit changes (grön knapp) → vänta på grön bock i Actions → klart! ✅
Redigeringsknappen ✏️ på recepten frågar efter det nya lösenordet direkt.
